# India state-map data

The state navigator is derived from the DataMeet Community Maps Project state-boundary dataset:

- Source: https://projects.datameet.org/maps/states/
- Licence: Creative Commons Attribution 2.5 India
- Local source copy: `data/geo/source/india-states.json`
- Adaptation: projected to a fixed SVG view box, rounded to integer coordinates and simplified for web display by `tools/build-state-map.mjs`

The map is used as a navigation aid. It is not described as an official government map.
